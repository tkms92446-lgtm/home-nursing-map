# はじめかた（初心者向け）

自分のパソコンで「訪問看護ステーションMAP」を開くための手順です。
上から順番に1つずつ進めてください。最初の1回だけ30分ほどかかります。2回目からは数分で開けます。

---

## 準備するもの（最初の1回だけ）

| 名前 | 何のためのもの？ |
| --- | --- |
| **Node.js** | このアプリを動かすためのソフト |
| **Docker Desktop** | 事業所のデータを保存する「データベース」を、簡単に用意するためのソフト |
| **厚労省のCSVファイル** | 事業所のデータ。以前ダウンロードした `jigyosho_130_all_20260709180342.csv` |

### 1. Node.js を入れる

1. https://nodejs.org/ja を開きます
2. 「**LTS**」と書かれた緑のボタンを押してダウンロードします
3. ダウンロードしたファイルを開き、「次へ」「続ける」を押してインストールします（設定は変えなくて大丈夫です）

### 2. Docker Desktop を入れる

1. https://www.docker.com/ja-jp/products/docker-desktop/ を開きます
2. 自分のパソコン（Mac / Windows）に合ったものをダウンロードしてインストールします
   - Mac の場合：「Apple チップ」か「Intel チップ」かを選びます（左上のりんごマーク →「このMacについて」で確認できます）
3. インストールしたら **Docker Desktop を起動**します
   - 画面上部（Mac）や右下（Windows）に **クジラのマーク** が出ていれば起動しています
   - アカウント登録を求められても「Skip（スキップ）」で大丈夫です
   - Windows の場合：「WSL」のインストールや再起動を求められることがあります。画面の案内どおりに進めてください

> 個人や小規模な利用なら Docker Desktop は無料です。

### 3. アプリのファイルをダウンロードする

1. https://github.com/tkms92446-lgtm/home-nursing-map を開きます
2. 緑色の「**Code**」ボタン →「**Download ZIP**」を押します
3. ダウンロードしたZIPファイルをダブルクリックして展開します
4. できた `home-nursing-map-main` フォルダを **デスクトップ** に移動します

### 4. CSVファイルを入れる

`home-nursing-map-main` フォルダの中の `data` → `raw` フォルダに、
厚労省のCSVファイル `jigyosho_130_all_20260709180342.csv` をコピーします。

> ファイル名が `jigyosho_130_all_20260709180342 1.csv` のように変わっていたら、`jigyosho_130_all_20260709180342.csv` に名前を変えてください。

## 「ターミナル」を開く

ここからは、文字でパソコンに指示を出す「ターミナル」という画面を使います。

- **Mac**：`command` + `スペース` を押して「ターミナル」と入力し、Enter
- **Windows**：スタートボタンを右クリック →「ターミナル」（または「Windows PowerShell」）

次に、アプリのフォルダへ移動します。
`cd ` （cd のあとに半角スペース）と入力してから、**`home-nursing-map-main` フォルダをターミナルの画面にドラッグ＆ドロップ**し、Enter を押します。

```
cd （ここにフォルダをドラッグすると場所が自動で入ります）
```

## 最初の1回だけ行う設定

以下を **1行ずつ** コピーしてターミナルに貼り付け、Enter を押してください。
1つ終わって、また文字が入力できる状態になってから次に進みます。

**① 必要な部品を入れる**（数分かかります）

```
npm install
```

**② 設定ファイルを作る**

Mac の場合：
```
cp .env.example .env.local
```
Windows の場合：
```
copy .env.example .env.local
```

**③ データベースを起動する**（初回は数分かかります。Docker Desktop を起動しておいてください）

```
docker compose up -d
```

**④ データベースの中に表を作る**

```
npm run db:migrate
```

`applied: 001_init.sql` と出れば成功です。

> 「接続できない」というエラーが出たら、10秒ほど待ってからもう一度実行してください（データベースの起動に少し時間がかかります）。

**⑤ 大阪府の事業所データを取り込む**

```
npm run data:osaka
```

`新規: 1879` と `成功: 1879` のような表示が出れば成功です。

---

## アプリを開く

```
npm run dev
```

`Ready` と表示されたら、ブラウザ（Chrome や Safari）で次のアドレスを開きます。

**http://localhost:3000**

大阪市周辺の地図と、訪問看護ステーションの一覧が表示されます。

- 「住所・地域から探す」：例）`大阪市天王寺区上本町6丁目` と入力
- 「現在地から探す」：ブラウザが位置情報の許可を聞いてくるので「許可」を押す
- 管理画面：http://localhost:3000/admin

---

## アプリを閉じる

1. ターミナルで `control` + `C`（Windows は `Ctrl` + `C`）を押します
2. データベースも止めたいときは次を実行します（データは消えません）

```
docker compose down
```

---

## 2回目以降の開き方

1. **Docker Desktop を起動**する（クジラのマークが出るまで待つ）
2. ターミナルを開いて、フォルダへ移動する（`cd ` ＋ フォルダをドラッグ）
3. 次の2つを実行する

```
docker compose up -d
npm run dev
```

4. ブラウザで http://localhost:3000 を開く

## うまくいかないとき

| 症状 | 対処 |
| --- | --- |
| `npm: command not found` / `npm は認識されません` | Node.js を入れたあと、ターミナルを一度閉じて開き直してください |
| `docker: command not found` / `Cannot connect to the Docker daemon` | Docker Desktop が起動していません。起動してクジラのマークが出てから再実行してください |
| `port is already allocated`（5432番） | パソコンに別の PostgreSQL が動いています。そのソフトを止めるか、Claude にご相談ください |
| 地図の背景が真っ白 | インターネット接続を確認してください（地図の画像は国土地理院から読み込みます） |
| 「現在地から探す」が使えない | ブラウザの位置情報が「ブロック」になっていないか確認してください。アドレスバー左のアイコンから変更できます |

困ったときは、ターミナルに出たエラーの文字をそのままコピーして、このスレッドに貼ってください。
